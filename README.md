# Hi there 👋  
This README demonstrates **all basic Markdown elements** and shows what each one means.  

---

## 1. Headings  
- `#` → Biggest heading  
- `##` → Section heading  
- `###` → Sub-heading  

---

## 2. Text Formatting  

### **Bold**
Use `**text**`  

### *Italic*
Use `*text*`  

---

## 3. Line Breaks  
End a line with two spaces or leave an empty line.  
Example:  
Line one  
Line two  

---

## 4. Horizontal Rule  
Used to divide sections.  
Type: `---`

---

## 5. Lists  

### Unordered List  


Example:  
- First thing  
- Second thing  
- Third thing  


---

## 6. Links  
Markdown link:  
`[Title](URL)`

Example:  
- [LinkedIn](https://google.com) ← This is a hyperlink  


---

## 7. Code Blocks  

### Inline Code  
Use backticks:  
`git init`

### Code Block  
Wrap with three backticks:  
```bash
git init
git add .
git commit -m "message"

```
